Security Report

Full OWASP audit. All findings resolved.

What we found & fixed

  • Spotify tokens exposed in URL → moved to hash fragments
  • Missing CSRF on OAuth → added state parameter + cookie
  • No brute force protection → rate limiting per email + per IP
  • Missing dashboard ownership check → added userId verification
  • Weak password policy → requires letter + digit
  • Global rate limits → switched to per-user keys

Security layers in place

  • JWT auth with scrypt password hashing
  • Zod validation on every API route — no unvalidated input
  • Parameterized SQL everywhere — zero injection risk
  • Security headers: HSTS, X-Frame-Options, Referrer-Policy
  • Spotify OAuth with CSRF state + Secure cookies
  • Error messages sanitized in production

Lessons Learned

What surprised us

  • Spotify's embed is a black box. No skip/next via postMessage. We built the full Web Playback SDK integration to get real voice control.
  • Token security is layers, not a single fix. Hash fragments, CSRF state, security headers, rate limiting — each protects against a different attack vector.
  • Color theming took 3 iterations. Global green → neutral gray → per-dashboard accent-derived surfaces. Each dashboard generates its own palette.
  • Parallel agents = superspeed. 3 audit agents, 3 fix agents simultaneously. Hours of work in minutes.
  • CLAUDE.md pays for itself. Every rule caught real bugs in the audit. Constraints are guardrails, not overhead.
